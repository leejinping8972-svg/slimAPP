# Design — 去掉电商能力并补齐前后台闭环

> 日期：2026-07-31 · 产品：luckdate · 状态：已确认直接落地（方案 1）

## 目标

1. 去掉商城、App 内下单、订单管理、优惠券相关逻辑与页面。  
2. 开通只保留「外部查单绑定」：命中商品 ID ∈ 基础设置 `slim_plan_product_ids` 则开通 28 天方案。  
3. 管理后台按新 IA 重建，补齐用户打卡记录与方案看板/实例列表，使前后台可运营闭环。

## 决策摘要

| 项 | 决定 |
|----|------|
| 开通方式 | 外部查单绑定；不做激活码；不做 App 内购 |
| Day28 | 仅报告 + 鼓励，不引导购买 |
| 后台订单/商品/券 | 删除 |
| 方案列表 | 数据看板 + 可筛选方案实例表 |
| 激活码管理 | 不做 |

## APP 变更

**删除 / 隐藏**
- 底栏 Tienda；路由 `/mall`、`/collection/**`
- 商品详情购买、欢迎券展示与核销
- Day28 复购 CTA / 浏览商品入口
- 激活码相关入口（若仍有）

**保留**
- 外部查单绑定（姓名 + 手机后四位）
- 绑定结果产品 ID 与 `slim_plan_product_ids` 比对后开通方案
- Ritual / Journey / Plan / 打卡 / Sunny 聊天主链路
- Day28 成果报告与鼓励文案

## 管理后台 IA

1. **管理员配置**：管理员列表、角色列表  
2. **用户管理**：用户列表、用户详情、用户打卡记录列表  
3. **方案列表**：28 天方案数据看板 + 方案实例表  
4. **系统设置**：基础设置（至少保留 `slim_plan_product_ids`；移除复购推荐/注册送券 config）

客服协助绑产品：在用户详情内「外部查单绑定」，只写绑定结果，不维护订单台账。
